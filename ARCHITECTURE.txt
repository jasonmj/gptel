                    gptel-workflow Architecture
                    ============================

┌─────────────────────────────────────────────────────────────────┐
│                         USER INTERFACE                           │
├─────────────────────────────────────────────────────────────────┤
│  gptel-workflow-menu (Transient)                                │
│    ├─ Start/Reset workflow                                       │
│    ├─ Run steps (plan/diff/tests/review/checklist)              │
│    └─ Utilities (retry/show output/show log)                    │
│                                                                   │
│  gptel-workflow-step-menu (Transient)                           │
│    ├─ Navigate (next/previous step)                             │
│    ├─ Actions (retry/edit ACs/continue)                         │
│    └─ View (output/log)                                          │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                      WORKFLOW ORCHESTRATION                      │
├─────────────────────────────────────────────────────────────────┤
│  gptel-workflow-state                                            │
│    ├─ current-step                                               │
│    ├─ acs / acs-tagged (AC1, AC2, ...)                          │
│    ├─ context / context-summary                                  │
│    ├─ plan / diff / tests / review / checklist                   │
│    ├─ continue / integration-tests-flag                          │
│    └─ preset-overrides / retry-count                             │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        WORKFLOW STEPS                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  1. PLAN                                                         │
│     Preset: strong-medium (gpt-4, temp=0.7)                     │
│     Input: ACs + Context                                         │
│     Output: Bulleted plan                                        │
│     Validation: ✓ bullets ✓ AC citations                        │
│                         ↓                                         │
│  2. DIFF                                                         │
│     Preset: strong-low (gpt-4, temp=0.3)                        │
│     Input: Plan + ACs + Context                                  │
│     Output: Unified diff                                         │
│     Validation: ✓ unified format ✓ AC citations                 │
│                         ↓                                         │
│  3. TESTS                                                        │
│     Preset: strong-low (gpt-4, temp=0.3)                        │
│     Input: Diff + ACs + Context                                  │
│     Output: Test diffs                                           │
│     Validation: ✓ test paths                                     │
│                         ↓                                         │
│  [3.5 INTEGRATION TESTS - Optional]                             │
│     Preset: strong-low (gpt-4, temp=0.3)                        │
│     Input: Diff + ACs + Context                                  │
│     Output: Integration test diffs                               │
│     Validation: ✓ test paths                                     │
│                         ↓                                         │
│  4. REVIEW                                                       │
│     Preset: strong-low (gpt-4, temp=0.3)                        │
│     Input: Diff + Tests + ACs                                    │
│     Output: Bulleted review (risks/missing/alternatives)         │
│     Validation: ✓ bullets                                        │
│                         ↓                                         │
│  5. CHECKLIST                                                    │
│     Preset: strong-low (gpt-4, temp=0.3)                        │
│     Input: Plan + Review + ACs                                   │
│     Output: Markdown checklist                                   │
│     Validation: None (final step)                                │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                     VALIDATION GATES                             │
├─────────────────────────────────────────────────────────────────┤
│  gptel-workflow--validate-plan                                   │
│    → Check: bullets present, AC IDs cited                        │
│                                                                   │
│  gptel-workflow--validate-diff                                   │
│    → Check: unified format, non-empty, AC IDs cited              │
│                                                                   │
│  gptel-workflow--validate-tests                                  │
│    → Check: non-empty, test paths touched                        │
│                                                                   │
│  gptel-workflow--validate-review                                 │
│    → Check: bullets present, non-empty                           │
│                                                                   │
│  Human confirmation: yes-or-no-p on validation failure           │
└─────────────────────────────────────────────────────────────────┘
                              ↓

                    Component Interaction Flow
                    ==========================

User Input → Transient UI → Workflow State → Step Runner →
  Preset Selection → Prompt Building → gptel-request →
    LLM Response → Validation Gate → Human Confirmation →
      State Update → Output/Log → Next Step


                         Data Flow
                         =========

      ACs (user input)
           ↓
    Tagged (AC1, AC2, ...)
           ↓
    Propagated to prompts
           ↓
    Cited in outputs
           ↓
    Validated in gates
